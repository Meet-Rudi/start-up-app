    File names

    Batch ID, optional name, kind, part — joined by double underscores.

    Batch IDTA-20261013-K7QX Case IDTA-20261013-K7QX-0003 InputTA-20261013-K7QX__goal-setting-smoke__input.yaml ResultsTA-20261013-K7QX__goal-setting-smoke__results__p01of02.yaml

    The date is the day of submission in Brussels. Results split into parts before 500k tokens; a case is never cut in two.

    The three kinds of case

    ModeWho writes the user's messagesEnds when
    scriptedYou — fixed replicas, sent in order whatever Rudi answersThe script runs out
    intentA tester LLM playing a persona with an objectiveSuccess or abort criterion met, or a limit is hit
    hybridYour script first, then the tester LLMAs for intent

    Stopping an intent case

    FieldMeaning
    success_whenDesired outcome, in plain words. Judged by an LLM after every Rudi reply.
    abort_whenA breach, e.g. medical advice. Ends the case as a violation.
    max_turnsCeiling on user messages.
    max_attemptsCeiling on messages in which the user pushes for the objective.
    on_limitfail (default) or pass — for probes where holding out is the win.

    Budgets

    Optional ceilings, in euro: model spend plus the AWS overhead estimate.

    batch:
  max_cost_eur: 2.00      # the whole batch
defaults:
  limits:
    max_cost_eur: 0.05    # each case (a case can set its own)

    Budgets count model spend plus the AWS overhead estimate (a small unit price per turn and per case). A case that would pass its ceiling stops as Over budget — the cure for an objective that is never reached. When the batch budget is spent, cases not yet started are not started. Leave them out and the arena's defaults apply.

    Who plays which part

    Three cascades, all the arena's own, tried in this order.

    RoleDoesModels
    RudiAnswers — the deployed Rudi engine, on the arena's keysgroq-gpt-oss-120b → ovh-gpt-oss-120b
    TesterWrites the simulated user's messages (intent, hybrid)tester-groq-qwen3.8-27b (free tier) → tester-ovh-llama-3.3-70b → tester-ovh-gpt-oss-20b
    JudgeChecks Rudi's replies against expect / success_when / abort_whenjudge-groq-gpt-oss-120b (free tier) → judge-ovh-gpt-oss-120b → judge-ovh-llama-3.3-70b

    The tester and judge try Groq's free tier first and move on to OVH before a call would go over a free-tier limit, or when a call fails.

    Model cascades & prices
    The arena's own models, in failover order, with their keys and prices. None of these keys belongs to live Rudi.
    
            
    
          
    
          
    Prices are euro per million tokens. list = the provider's published price; estimate = our best figure, not yet confirmed; free tier = no charge, within the provider's published limits. Limits are requests (rpm, rpd) and tokens (tpm, tpd) per minute and per day. Prices not checked for 90 days are flagged. Separate keys only separate quota when they come from a separate Groq organisation or OVH project.
